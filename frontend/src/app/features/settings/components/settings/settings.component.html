Einstellungen

Parameter der Wurf-Erkennung zum schnellen Testen

Zeigt im Spiel ein Eingabefeld, um Punkte von Hand zu buchen. Als Rückfallebene gedacht, falls die Kameraerkennung fehlschlägt.

Zeigt im Spiel neben den Würfen die Option diese zu bestätigen. Wenn nicht aktiv, wird automatisch nach 3 Würfen weitergezählt.

Lässt den Server bei jeder Kalibrierung die Zwischenschritte als Bilder ablegen. Nur zum Testen - im Normalbetrieb aus.

Lässt den Server bei jedem Wurf die Zwischenschritte der Pfeil-Erkennung als Bilder ablegen. Nur zum Testen - im Normalbetrieb aus.

Zeigt in der Kamera-Ansicht live, was die client-seitige Wurf-Erkennung gerade tut. Betrifft nur die Anzeige auf diesem Gerät, nichts am Server.
