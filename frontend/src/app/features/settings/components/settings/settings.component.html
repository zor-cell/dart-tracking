Einstellungen

Parameter der Wurf-Erkennung zum schnellen Testen

Zeigt im Spiel ein Eingabefeld, um Punkte von Hand zu buchen. Als Rückfallebene gedacht, falls die Kameraerkennung fehlschlägt.

Lässt den Server bei jeder Kalibrierung die Zwischenschritte als Bilder ablegen (siehe Debug-Skripte). Nur zum Testen — im Normalbetrieb aus.

Lässt den Server bei jedem Wurf die Zwischenschritte der Pfeil-Erkennung als Bilder ablegen. Nur zum Testen — im Normalbetrieb aus.
